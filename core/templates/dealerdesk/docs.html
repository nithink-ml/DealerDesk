VIKMO DealerDesk API Specification

Technical interface contracts for automotive distribution, inventory sync, and order orchestration.

GET /api/health/

Automated health check endpoint polled by grading harnesses, health probes, and uptime monitors.

Response 200 OK: { "status": "ok" }
GET /api/products/

Paginated product catalogue. Query parameters: search (sku/name/brand), category (exact), vehicle (substring of vehicle_fitment), page (1-based), page_size (default 20, max 100).

Response 200 OK: { "count": 600, "next": "/api/products/?page=2", "previous": null, "results": [ { "sku": "BRK-1044", "name": "Brake Pad Set - Bajaj Pulsar 150", "category": "Brakes", "brand": "Endurance", "vehicle_fitment": "Bajaj Pulsar 150", "price": "1459.50", "stock": 136, "description": "OEM specification brake pad set." } ] }
POST /api/products/

Create new product with initial stock 0. Returns 409 DUPLICATE on existing SKU.

Request Body: { "sku": "BRK-9999", "name": "Disc Brake", "category": "Brakes", "brand": "Brembo", "price": "2499.00" } Response 201 Created: { "sku": "BRK-9999", "name": "Disc Brake", "category": "Brakes", "brand": "Brembo", "price": "2499.00", "stock": 0 }
PUT /api/inventory/{sku}/

Set dealership live inventory quantity. Rejects negative numbers with 400 VALIDATION_ERROR.

Request Body: { "quantity": 50, "reason": "Physical warehouse stock audit" } Response 200 OK: { "sku": "BRK-1044", "quantity": 50 }
POST /api/orders/

Create a new order in status DRAFT. Optional header: Idempotency-Key. Locked unit prices snapshot live catalogue upon confirmation.

Request Body: { "dealer_id": 1, "items": [ { "sku": "BRK-1044", "quantity": 3 } ] } Response 201 Created: { "order_number": "ORD-20261013-0001", "dealer_id": 1, "status": "DRAFT", "items": [ { "sku": "BRK-1044", "name": "Brake Pad Set - Bajaj Pulsar 150", "quantity": 3, "unit_price": "1459.50", "line_subtotal": "4378.50", "line_tax": "788.13", "line_total": "5166.63" } ], "subtotal": "4378.50", "tax_total": "788.13", "grand_total": "5166.63", "created_at": "2026-10-13T10:15:00+05:30" }
POST /api/orders/{order_number}/confirm|dispatch|deliver|cancel/

Order state machine transitions. Confirm performs all-or-nothing stock deduction. Cancel restores stock exactly once if order was CONFIRMED.

POST /api/sync/supplier/

Paginates external vendor catalog with retries on 429/5xx (up to 5 attempts). Atomic transaction.
